# CLM_Inteligente
“CLM para contratos públicos com apoio de IA” é uma Prova de Conceito (Proof of Concept - PoC) busca demonstrar a viabilidade técnica e operacional da uso dessas tecnologias no contexto da Administração Pública da dissertação "Inteligência Artificial Aplicada à Gestão do Ciclo de Vida de Contratos Públicos"
